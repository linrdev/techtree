# Design and assets

- Visual target: user-selected option 3, refined with ImageGen on 2026-10-11.
- Headings: Manrope, self-hosted through Fontsource.
- Body: Inter, self-hosted through Fontsource.
- UI icons: Phosphor; technology icons: Font Awesome Brands.
- Browser logos: `@browser-logos` packages, source https://github.com/alrra/browser-logos.
- Hero room and TechTree branch mark: generated with built-in ImageGen using the selected design as visual reference. The assets are stored in `public/assets/`.
- Chart: Recharts, using illustrative sample visits.

The generated hero asset depicts a softly lit ivory room with a wood chair and a ceramic vase on a pale table. The logo asset recreates the blue branching stem from the chosen reference. Brand marks shown within the sample inspector are demo signals, not endorsements.
